`main.py` writes a single sentence to `/output/entry.txt`:

> My grandmother's chicken soup, ladled into a chipped blue bowl while snow sealed the windows shut, still tastes like winter deciding, for once, to be kind.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
